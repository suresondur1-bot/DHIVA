# Goal: Create a new stock correction: a Select Store popup appears first - in the Store box type the store code 157-IP1 and wait a couple of seconds for the suggestion, then select the suggestion shown, then click Continue. Then in the Item box type item code KI-RA-N-0901-PH and wait for the suggestion then select it, and wait for the item row to appear in the table. In that row, click the Batch No Current dropdown, type KILLA12, wait a couple of seconds for the suggestion, then select the batch (do not just click it - it must be picked with Enter or it will not register).Then select the batch From  unit Type KILLA12 for search and select the one that comes,
 Then set MRP Current to 51 and Correction Qty to 50. Then click Save and stop
# Start: https://sqa.narayanahealth.org/phrweb/stock-correction-new
# Steps: 10

  1. clear          #storeInput   # Store field is empty
  2. clear          #storeInput   # Store input becomes empty
  3. click          #ngb-typeahead-1-36   # Store 157-IP1 is selected and Continue becomes enabled
  4. click          #continueButton   # Modal closes and correction document body becomes usable
  5. search_select  #itemInput   # Item suggestion appears and is selected, adding a row to the table
  6. search_select  ng-select[name="batch"]   # Batch No Current dropdown shows KILLA12 suggestion and it is selected
  7. search_select  tbody > tr > td:nth-of-type(3) > stock-correction-batch-search > ng-select   # Batch from Unit value selected
  8. type           table > tbody > tr > td:nth-of-type(5) > input   # MRP Current shows 51
  9. type           table > tbody > tr > td:nth-of-type(9) > input   # Correction Qty field shows 50
 10. click          div:nth-of-type(1) > stock-correction-button > div > div:nth-of-type(2) > button:nth-of-type(2)   # Correction document is saved
