# Goal: Create a new stock correction: a Select Store popup appears first - in the Store box type the store code 157-IP1 and wait a couple of seconds for the suggestion, then press ArrowDown and press Enter to select it, then click Continue. Then in the Item box type item code KI-RA-N-0901-PH and wait for the suggestion then select it, and wait for the item row to appear in the table. In that row, click the Batch No Current dropdown, type KILLA12, wait a couple of seconds for the suggestion, then press ArrowDown and press Enter to select the batch (do not just click it - it must be picked with Enter or it will not register). Then set MRP Current to 51 and Correction Qty to 50. Then click Save and stop
# Start: https://sqa.narayanahealth.org/phrweb/stock-correction-new
# Steps: 9

  1. clear          #storeInput   # Store input cleared
  2. clear          #storeInput   # Store input is empty
  3. click          #ngb-typeahead-1-36   # Store 157-IP1 gets selected and Continue button enables
  4. click          #continueButton   # Modal closes and correction document body becomes usable
  5. search_select  #itemInput   # A new row appears in the items table for the selected item
  6. search_select  ng-select[name="batch"]   # Batch suggestion KILLA12 appears for selection
  7. type           table > tbody > tr > td:nth-of-type(5) > input   # MRP Current shows 51
  8. type           table > tbody > tr > td:nth-of-type(9) > input   # Correction Qty shows 50
  9. click          div:nth-of-type(1) > stock-correction-button > div > div:nth-of-type(2) > button:nth-of-type(2)   # The stock correction is saved
